# Проверка VPN из России (лист для тестера)

Нужно ~30 минут и телефон с приложением **Hiddify**. Личная ссылка — это ваш ключ: никому её не пересылайте, не
публикуйте скриншоты со ссылкой, не присылайте ссылку мне обратно. Присылайте только то, что просит последний раздел.

Схема: ваш телефон → сервер-вход в Германии (de1) → сервер-выход в Финляндии. Обычные сайты должны показывать
Финляндию. Google/YouTube могут показывать Германию — это задумано.

## 0. Проверка без ссылки (1 минута, можно до установки)

Откройте в браузере телефона **в мобильной сети**:

1. `https://de1.xn----8sba1cvaif4e.com:8443/` — должна открыться страница **404 Not Found**. Это значит: имя
   найдено и порт 8443 доступен.
2. `https://de1.xn----8sba1cvaif4e.com/` — откроется страница-«маскировка» или ошибка сертификата/400. Это нормально.
   Не открывается совсем (долго грузится, «нет соединения») — запишите: **вход не доступен из вашей сети**.

Повторите то же в домашнем Wi-Fi.

## 1. Подключение (Android и iPhone одинаково)

1. Установите Hiddify (Google Play / App Store; для APK: github.com/hiddify/hiddify-app/releases).
2. Скопируйте личную ссылку (начинается с `https://`, заканчивается на `compat=hiddify-pinned`).
3. Hiddify → **Новый профиль** → **Добавить из буфера обмена**.
4. В профиле должен быть **один** сервер («fin1 · via de1»). Если серверов несколько или есть «balance»/«lowest» —
   остановитесь и напишите.
5. Нажмите **Подключить**, разрешите VPN-соединение.

## 2. Что проверить (в мобильной сети, потом в Wi-Fi)

Отмечайте **ОК / НЕ ОК / НЕ ПРОВЕРЯЛ** по каждому пункту:

| № | Проверка | Ожидание |
|---|---|---|
| 1 | Профиль импортировался без ошибки | один сервер |
| 2 | Подключение установилось (значок VPN, таймер идёт) | за 10–20 с |
| 3 | Любой сайт по https (например wikipedia.org) | открывается |
| 4 | Страница «мой IP» (например ifconfig.me в браузере) | **Финляндия**, не ваш оператор |
| 5 | Telegram: отправить сообщение, открыть чужой канал | работает |
| 6 | YouTube: длинное видео **5 минут** без остановок | без зависаний |
| 7 | YouTube Shorts **без входа в аккаунт**: 8 разных роликов подряд, каждый до конца (≥ 30 с) | ни один не зависает и не пишет «недоступно» |
| 8 | То же в Shorts **с входом в аккаунт** | так же |
| 9 | Кнопка «Обновить» у профиля | без ошибки, работа не прерывается |
| 10 | Закрыть и снова открыть приложение → «Подключить» | подключается |
| 11 | Переключить мобильные данные ⇄ Wi-Fi при включённом VPN | через ≤ 30 с работает снова |
| 12 | Режим полёта на 10 с, затем выключить | VPN переподключается |

Для пунктов 6–7 считайте **каждый** сбой (зависание, «недоступно», чёрный экран), даже если потом пошло.

## 3. Если не работает — определите, где именно

Ответьте по порядку, остановитесь на первом «нет»:

1. **Имя не находится?** Шаг 0.1 даёт «сайт не найден / DNS» → *сбой DNS* (поменяйте DNS телефона на 1.1.1.1 или
   8.8.8.8 и повторите; запишите результат).
2. **Шаг 0.1 открывается, а профиль не загружается** → ссылка набрана с ошибкой или отозвана (ошибка 404). Попросите новую.
3. **Профиль загрузился, «Подключить» висит/тайм-аут, а шаг 0.2 не открывается** → *вход заблокирован у вашего
   оператора* (запишите оператора и тип сети).
4. **Шаг 0.2 открывается, подключение рвётся сразу** → *сбой рукопожатия* (запишите время и сообщение приложения).
5. **Подключено, но сайты не открываются** → *сбой маршрута* (попробуйте другой сайт, потом ifconfig.me).
6. **Всё работает, кроме YouTube/Shorts** → *отказ сервиса назначения* (запишите, что именно: видео не грузится,
   «недоступно», зависание на какой секунде).

## 4. Что прислать (без личных данных)

```
Сеть: мобильная / Wi-Fi дом   Оператор: (МТС / Билайн / Мегафон / Tele2 / Ростелеком / другое — без номера и адреса)
Телефон: Android или iPhone, версия Hiddify
Пункты 1–12: ОК / НЕ ОК / НЕ ПРОВЕРЯЛ (по каждой сети отдельно)
Пункт 7: сколько роликов проверено, сколько сбоев
Пункт 4: страна в «мой IP»
Если сбой: какой из шести типов выше + время + текст ошибки приложения
```

Не присылайте: ссылку, скриншоты со ссылкой, свой точный адрес, номер телефона, IP-адрес.
