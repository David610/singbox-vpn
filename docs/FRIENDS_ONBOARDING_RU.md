# Подключение для друзей (Android и iPhone)

Вам нужна только **личная ссылка**, которую пришлёт администратор. Ничего настраивать на сервере и вводить вручную не нужно.
Ссылка — это ваш личный ключ. Не пересылайте её никому и не публикуйте скриншоты со ссылкой.

> Статус: инструкция подготовлена, но **ещё не проверена на реальных телефонах в России** (ни на Android, ни на iPhone).
> Проверка схем подключения выполнена только на сервере и на движке Hiddify (hiddify-core), не в самом приложении.
> См. `docs/qualification/2026-10-25/FRIENDS_ROLLOUT_ACCEPTANCE.md`.

## Два вида ссылок (важно)

Администратор скажет, какая у вас схема. Не меняйте окончание ссылки сами.

- **Схема «вход через Россию → выход в Европе»** (основная для этой установки): ссылка заканчивается на `?format=singbox&compat=hiddify-pinned`. В профиле **один** сервер, переключать ничего не нужно.
  Ссылка с окончанием `?format=hiddify` для этой схемы **не подходит**: сервер её отклоняет (ошибка 400, `relay_route_needs_pinned_profile`), потому что обычная ссылка не умеет передать «вход через Россию» и приложение подключилось бы к европейскому серверу напрямую, не сообщив об этом.
  Если в списке видно больше одного сервера или есть «balance»/«lowest», это не тот профиль — напишите администратору.
- **Схема «через Финляндию»** (отдельный сервер без российского входа): ссылка заканчивается на `?format=hiddify`. В профиле два варианта: **Reality** и **Hysteria2**.

Все шаги ниже одинаковы для обеих схем; различие только в списке серверов (шаг «Если нет интернета»).

## Android

1. Установите **Hiddify** из Google Play (или APK с https://github.com/hiddify/hiddify-app/releases).
2. Скопируйте ссылку от администратора (она начинается с `https://`).
3. Откройте Hiddify → **Новый профиль** (New Profile) → **Добавить из буфера обмена** (Add from Clipboard).
4. Подождите, пока профиль загрузится. Проверьте список серверов: для схемы через Россию там один сервер; для схемы через Финляндию — **Reality** и **Hysteria2**.
5. Нажмите большую кнопку **Подключить** (Connect). Разрешите создание VPN-соединения, когда Android спросит.
6. Если через 20–30 секунд интернета нет: при двух вариантах (схема через Финляндию) выберите другой вариант (**Hysteria2** вместо **Reality** или наоборот) и сообщите администратору, какой сработал. При одном сервере переключать нечего — сообщите администратору текст ошибки.
7. Проверка: откройте любой сайт, затем YouTube (в том числе Shorts).

Android с агрессивной экономией батареи (HONOR, Xiaomi, Huawei): в настройках батареи разрешите Hiddify работу в фоне («Без ограничений»), иначе подключение может обрываться.

## iPhone

1. Установите **Hiddify** из App Store. Если приложения нет в App Store вашей страны, сообщите администратору — не меняйте регион и Apple ID самостоятельно без инструкции.
2. Скопируйте ссылку от администратора (она начинается с `https://`).
3. Откройте Hiddify → **+** → **Добавить из буфера обмена**.
4. Дождитесь загрузки профиля и проверьте список серверов (как на Android, шаг 4). Нажмите **Подключить**, разрешите добавление VPN-конфигурации (потребуется Face ID или пароль).
5. Если интернета нет через 20–30 секунд: при двух вариантах выберите другой (Reality ↔ Hysteria2) и сообщите администратору, какой работает; при одном сервере сообщите администратору текст ошибки.


## Обновление профиля и переподключение

- Профиль обновляется кнопкой **Обновить** (значок обновления рядом с профилем). Ваши данные для входа при этом **не меняются**.
- После перезапуска приложения профиль остаётся в списке; достаточно нажать **Подключить**.
- Если ссылка перестала работать (ошибка 404), администратор отключил или заменил её — запросите новую.

## Что делать, если не работает

1. Проверьте дату и время на телефоне: они должны устанавливаться автоматически.
2. Если есть два варианта подключения — переключите (Reality ↔ Hysteria2); затем отключите и снова включите VPN.
3. Попробуйте другую сеть (Wi-Fi вместо мобильной связи или наоборот).
4. Напишите администратору: **что показывает приложение**, мобильная сеть или Wi-Fi, какой оператор. Не присылайте ссылку.
