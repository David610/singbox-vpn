# HIDDIFY_ANDROID.md

Инструкция для обычного пользователя Android (включая HONOR MagicOS).
Никаких серверных секретов здесь нет — только то, что видит пользователь.

## Подключение

1. Установите **Hiddify** из Google Play (или APK с
   https://github.com/hiddify/hiddify-app, если Google Play недоступен).
2. Скопируйте вашу ссылку подписки — её пришлёт администратор. Она
   выглядит так:
   `https://sub.example.com:8443/sub/<длинный-случайный-токен>?format=hiddify`
3. Откройте Hiddify → **New Profile** → **Add from Clipboard**
   («Добавить из буфера обмена»).
4. Hiddify скачает профиль — в нём будут два способа подключения:
   **Reality** и **Hysteria2**. Ничего вводить вручную не нужно (UUID,
   ключи REALITY, SNI, пароль Hysteria2, порты — всё уже внутри ссылки).
5. При первом подключении Android спросит разрешение на создание VPN
   ("Подключение запрашивает разрешение на настройку VPN-соединения..."
   ) — нажмите **Разрешить/OK**.
6. Нажмите **Connect** (кнопка подключения).
7. По умолчанию подписка сразу подключает вас через **Reality**
   (детерминированно, не по результатам гонки скоростей) — это
   рекомендуемый консервативный транспорт для ограничительных сетей.
   Вы можете вручную переключиться на **Hysteria2** или на **auto**
   (встроенная функция sing-box `urltest` — она проверяет только
   быстрое HTTPS-соединение с серверами Google, а не работу Telegram)
   в списке серверов Hiddify. См. `docs/TELEGRAM_TROUBLESHOOTING.md`
   для раздельного тестирования транспортов.

## Если не подключается

- Попробуйте вручную переключиться между профилями Reality/Hysteria2 в
  списке серверов Hiddify — один из двух транспортов рассчитан на то,
  чтобы работать, даже если другой заблокирован.
- Проверьте, что дата/время на телефоне выставлены правильно
  (автоматически, через сеть) — REALITY чувствителен к рассинхронизации
  часов.
- Обновите ссылку подписки у администратора, если она могла быть
  отозвана.

## HONOR MagicOS: батарея и фон

MagicOS (и многие другие Android-прошивки с агрессивной экономией
батареи) может "выгружать" Hiddify из памяти в фоне, обрывая
соединение:

1. **Настройки → Батарея → Расход батареи по приложениям → Hiddify** →
   выберите **"Без ограничений"** / **"Manage manually"** → включите
   **Auto-launch**, **Secondary launch**, **Run in background**.
2. **Настройки → Приложения → Hiddify → Battery** → отключите
   **"Оптимизация батареи"** для Hiddify.
3. Закрепите Hiddify в списке недавних приложений (свайп вниз/значок
   замка на карточке приложения), чтобы система не закрывала его
   первым при нехватке памяти.

## Приватность

Ссылка подписки — это ваш личный ключ доступа. Не пересылайте её
другим людям: любой, у кого она есть, сможет подключаться под вашим
именем, пока администратор не отзовёт (rotate) токен.
